# MAISON VELLORE

Site estático one-page da empresa fictícia MAISON VELLORE, criado para um vídeo demonstrativo Hostinger x Otávio Miranda.

## Aviso

Esta empresa não existe. Todos os nomes, histórias, contatos e endereços presentes neste projeto são fictícios e foram gerados para fins educacionais e demonstrativos.

## Rodando localmente

Use qualquer servidor HTTP simples na raiz do projeto. Exemplo com Python:

```bash
python3 -m http.server 8000
```

Depois, abra `http://localhost:8000`.

## Estrutura

- `index.html`: página principal
- `styles/main.css`: estilos do site
- `assets/monogram.svg`: monograma da marca
- `content/copy.md`: texto editorial de referência

## Publicação

O destino oficial é o repositório `otaviomirandabr19/maison-vellore`, com publicação via GitHub Pages servindo da branch `main` na raiz.
